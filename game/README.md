# Медвежьи Приключения 🐻

3D-платформер в духе Super Bear Adventure на Godot 4.3 с мультиплеером
по локальной сети (Wi-Fi) и автосборкой APK для Android.

## Как получить APK

APK собирается автоматически GitHub Actions при каждом изменении игры:

1. Откройте вкладку **Releases** репозитория → релиз **apk-latest** →
   скачайте `BearAdventure.apk` прямо на телефон.
2. Откройте файл и разрешите установку из неизвестных источников.

(Альтернатива: вкладка Actions → последний запуск «Build Android APK» →
артефакт `BearAdventure-APK`.)

## Мультиплеер по Wi-Fi

1. Все игроки подключаются к **одной сети Wi-Fi**.
2. Один игрок нажимает **«Создать игру (по Wi-Fi)»** — он становится хостом.
3. Остальные нажимают **«Присоединиться к игре»** — хост находится
   автоматически (UDP-broadcast). Если сеть блокирует broadcast,
   введите IP хоста вручную (хост видит свой IP в правом верхнем углу).

Порты: игра — 8910/UDP, обнаружение — 8911/UDP.

## Игра

- **Медвежья деревня** — хаб: старейшина даёт задание, два портала.
- **Солнечные луга** — платформинг, монеты, грибы-вредины.
- **Снежные вершины** — открывается после сбора 15 монет; восхождение
  по спиральным уступам к золотой звезде = победа.
- Врагов можно победить прыжком сверху или ударом (кнопка «Удар»).
- Монеты и прогресс общие на всех игроков (кооператив).

## Управление

- **Телефон:** виртуальный джойстик слева, «Прыжок»/«Удар» справа,
  свайп по правой части экрана — камера.
- **ПК (для отладки):** WASD/стрелки, Space — прыжок, E/ЛКМ — удар,
  мышь — камера (клик захватывает, Esc отпускает).

## Разработка

Проект открывается в Godot 4.3+ (папка `game/`). Все сцены и миры
строятся кодом, бинарных ассетов нет. Локальная сборка APK — как в
`.github/workflows/build-apk.yml`.
