## 1. Unity-проект «Медвежьи Приключения»

Ветка `claude/super-bear-adventure-clone-twher0`, папка `unity/`.
**Unity 6000.0.80f1**, URP 17.0.4, сборка под Android (arm64).

Это не заготовка, а работающая игра: 564 файла, шесть миров, UDP-мультиплеер,
магазин, достижения, одиннадцать собственных шейдеров.

### Сборка работает и проверена

- **76 запусков** workflow `build-unity-apk.yml`, последние пять подряд —
  зелёные (последняя 31.07.2026).
- Готовый APK опубликован в релизе с тегом **`apk-unity`** (26.07.2026).
- Секреты `UNITY_USERNAME` / `UNITY_PASSWORD` **уже заведены** в настройках
  AR2 и рабочие — иначе job `check-credentials` заблокировал бы сборку и
  релиз бы не появился.

Лицензия — бесплатная **Unity Personal**, активируется парой почта+пароль
через `RageAgainstThePixel/activate-unity-license@v2`. Серийный номер не нужен.
Порядок настройки описан в `unity/LICENSE_SETUP.md`.

Время сборки — 25–45 минут (установка Unity на раннер + IL2CPP под ARM64),
повторные быстрее за счёт кэша `Library`.

## 2. Главное: проект устроен так, что редактор не нужен

Это ключевая находка. В репозитории **нет ни одной сцены `.unity`, ни одного
префаба, ни одного сериализованного ассета Unity**. Всё создаётся кодом:

| Механизм | Файл | Что делает |
|---|---|---|
| Генерация сцены при сборке | `Assets/Editor/BuildScript.cs` | создаёт `Main.unity`, URP-ассеты, настройки плеера — прямо в CI |
| Настройки импорта | `Assets/Editor/ModelImportSettings.cs` | `AssetPostprocessor`: риг, петли анимаций, sRGB, сжатие — вместо `.meta` |
| Загрузка моделей | `Assets/Scripts/Game/Res.cs` | `Resources.Load` по пути, без ссылок в инспекторе |
| Свои шейдеры | `Assets/Shaders/*.shader` | 11 штук; принудительно в Always Included Shaders |
| Проверка кода без Unity | `tools/csharp-check/check.sh` | компилирует все `Assets/**/*.cs` через `mcs` против `UnityStubs.cs` |

Именно это снимает возражение «без Unity Editor сцены придётся писать вслепую
в YAML с ручными GUID». Здесь сцены вообще нет как файла — она строится
скриптом, а скрипт я правлю как обычный C# и проверяю за секунды через
`check.sh`, не дожидаясь 40-минутной сборки.

**Для игры по БЖЖ этот подход переносится целиком.**

## 3. Что переиспользуем напрямую

1. **`build-unity-apk.yml`** — включая обходные пути, которые уже стоили
   отладки: определение changeset через `unity-changeset`, ручная установка
   Unity Hub с обёрткой `/usr/bin/unity-hub` (иначе `unity-setup` падает с
   `spawn unity-hub ENOENT`), очистка диска раннера, публикация в релиз.
2. **`BuildScript.cs`** — каркас: `Prepare()` → URP → PlayerSettings →
   шейдеры → сцена → `BuildPipeline.BuildPlayer`.
3. **`ModelImportSettings.cs`** — и это прямо про наш пак: он уже настроен на
   импорт «голых» FBX без `.meta`, срезает Blender-префиксы вида
   `Armature|Idle` с имён клипов и расставляет зацикливание. Модели монстров
   в медвежьем проекте — из паков Quaternius, то есть тот же поставщик, что
   и Universal Base Characters.
4. **`tools/csharp-check/`** — `mcs` + заглушки Unity API. Обязательно тащим:
   без него любая опечатка стоит 40 минут CI.

## 4. Что придётся делать иначе

- Медвежий проект использует **Legacy-риг** (клипы на компоненте `Animation`,
  играются по имени) — сознательно, чтобы не заводить ассет
  `AnimatorController`. Для БЖЖ этого мало: нужны плавные переходы между
  позициями партера и смешивание. Значит — **Humanoid + `AnimatorController`,
  создаваемый кодом** через `UnityEditor.Animations.AnimatorController` в
  `BuildScript`. Так принцип «никаких ассетов в репозитории» сохраняется.
- Пак Universal Base Characters имеет **Humanoid-риг**, что как раз и нужно
  для ретаргета. См. `ASSETS.md`.
- Парных анимаций борьбы в партере не даёт ни один бесплатный пак — это
  по-прежнему главный риск, см. §4 в `PLAN.md`. Решается процедурно (IK и
  привязка костей), а не готовыми клипами.

## 5. Godot-версия — не конкурент, а запасной аэродром

В той же ветке лежит папка `game/` — та же игра на Godot 4.3 (`godot.yml`,
релиз `apk-latest`). Её трогать не нужно. Полезна она одним: если сборка
Unity когда-нибудь встанет из-за лицензии, есть проверенный путь без неё.
