# Активация лицензии Unity (нужно сделать один раз)

Unity не собирает проект без активированной лицензии — даже бесплатную
Personal нужно активировать. Этот шаг нельзя автоматизировать: он требует
входа в ваш аккаунт Unity. Пароль от аккаунта мне сообщать не нужно.

Всё делается за 5 минут.

## Шаг 1. Получить файл активации (.alf)

1. Откройте вкладку **Actions** репозитория.
2. Слева выберите workflow **«Unity — получить файл активации (шаг 1)»**.
3. Нажмите **Run workflow** → **Run workflow**.
4. Дождитесь завершения (~1 минута).
5. Внизу страницы запуска скачайте артефакт **Unity_v2022.3.76f1.alf**
   и распакуйте архив — внутри файл с расширением `.alf`.

## Шаг 2. Обменять .alf на лицензию .ulf

1. Откройте https://license.unity3d.com/manual
2. Войдите в свой аккаунт Unity (тот же, где вы создали организацию).
3. Загрузите файл `.alf` из шага 1.
4. Выберите **Unity Personal Edition** →
   **"I don't use Unity in a professional capacity"**.
5. Нажмите **Download license** — скачается файл `.ulf`.

## Шаг 3. Положить лицензию в секреты GitHub

1. Откройте `.ulf` в текстовом редакторе (Блокнот подойдёт).
2. Выделите и скопируйте **всё содержимое файла** целиком
   (это XML, начинается с `<?xml`).
3. В репозитории: **Settings → Secrets and variables → Actions →
   New repository secret**.
4. Имя секрета: `UNITY_LICENSE`
5. Значение: вставьте скопированный текст.
6. Нажмите **Add secret**.

## Шаг 4. Собрать APK

1. Вкладка **Actions** → workflow **«Build Unity APK»** → **Run workflow**.
2. Сборка идёт долго — примерно 20–40 минут (Unity качает образ,
   компилирует IL2CPP под ARM64).
3. Готовый APK появится в разделе **Releases** под тегом **apk-unity**,
   а также в артефактах запуска.

После этого каждое изменение в папке `unity/` будет автоматически
пересобирать APK.

## Если что-то пошло не так

- **Сборка сразу пропускается** — секрет `UNITY_LICENSE` не найден.
  Проверьте, что имя секрета написано ровно так, заглавными буквами.
- **Ошибка лицензии в логе** — файл `.ulf` скопирован не полностью
  или лицензия выдана для другой версии Unity. Повторите шаги 1–3.
- **Нет места на диске в раннере** — сообщите мне, увеличу очистку
  или переключу сборку на менее тяжёлый вариант.
