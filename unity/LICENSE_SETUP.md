# Доступ к Unity для сборки APK (нужно сделать один раз)

Unity не собирает проект без активированной лицензии — даже бесплатную
Personal нужно активировать. Автоматизировать это полностью нельзя:
активация требует входа в аккаунт Unity.

## Важно про безопасность

Раньше существовал способ без пароля: файл лицензии `.ulf` клался в секрет
`UNITY_LICENSE`. **GameCI полностью удалил его** — в текущей версии
инструмента сборки остались только два варианта: аккаунт (почта + пароль +
серийный номер) или платный лицензионный сервер. Поэтому пароль от аккаунта
Unity придётся положить в секреты GitHub.

**Настоятельно рекомендую завести отдельный аккаунт Unity только для сборки**
(любая почта, бесплатная Personal-лицензия). Причины:

- репозиторий публичный, и хотя секреты не видны в логах и недоступны из
  форков, доступ к ним есть у любого, кто имеет право писать в репозиторий;
- если что-то утечёт, пострадает пустой технический аккаунт, а не ваш
  основной с проектами и организацией.

Мне пароль сообщать не нужно — вы вводите его прямо в настройках GitHub.

## Шаг 1. Аккаунт и лицензия Unity

1. Зайдите на https://id.unity.com (или зарегистрируйте отдельный аккаунт).
2. Убедитесь, что у аккаунта активирована лицензия **Unity Personal**
   (бесплатная). Если её нет — https://unity.com/products/unity-personal,
   кнопка *Get started*.

## Шаг 2. Найти серийный номер

1. Откройте https://id.unity.com → **My Account** → **My Seats**
   (или https://id.unity.com/en/subscriptions).
2. Найдите свою лицензию Unity Personal и скопируйте **Serial Number** —
   строка вида `XX-XXXX-XXXX-XXXX-XXXX-XXXX`.

Если серийного номера не видно, скажите мне — переключу сборку на
альтернативный способ активации, который работает без него.

## Шаг 3. Добавить три секрета в GitHub

Репозиторий → **Settings** → **Secrets and variables** → **Actions** →
**New repository secret**. Добавьте по очереди:

| Имя секрета      | Значение                                  |
|------------------|-------------------------------------------|
| `UNITY_EMAIL`    | почта аккаунта Unity                      |
| `UNITY_PASSWORD` | пароль от этого аккаунта                  |
| `UNITY_SERIAL`   | серийный номер из шага 2                  |

Имена должны совпадать точно, заглавными буквами.

⚠️ У аккаунта не должно быть включено двухфакторное подтверждение (2FA) —
иначе автоматический вход не пройдёт. Ещё один довод в пользу отдельного
технического аккаунта.

## Шаг 4. Собрать APK

1. Вкладка **Actions** → workflow **Build Unity APK** → **Run workflow**.
2. Сборка идёт долго: 20–40 минут (Unity качает образ и компилирует
   IL2CPP под ARM64).
3. Готовый APK появится в **Releases** под тегом **apk-unity**, а также
   в артефактах запуска.

Дальше каждое изменение в папке `unity/` пересобирает APK автоматически.

## Если что-то пошло не так

- **Сборка сразу пропускается** — не найден один из трёх секретов;
  в логе job «Проверка доступа к Unity» написано, какого именно.
- **Ошибка активации / неверные данные** — проверьте серийный номер и
  что 2FA выключена.
- **Нет места на диске у раннера** — сообщите, увеличу очистку.
- **Не хотите класть пароль в секреты** — это разумно; тогда остаётся
  Godot-версия в папке `game/`, она собирается без всякой лицензии
  и APK уже лежит в релизе `apk-latest`.
