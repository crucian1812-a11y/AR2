# Доступ к Unity для сборки APK (нужно сделать один раз)

Unity не собирает проект без активации лицензии — даже бесплатную Personal
нужно активировать. Полностью автоматизировать это нельзя: активация
требует входа в аккаунт Unity.

Нужно добавить **два секрета**: почту и пароль от аккаунта Unity.

> **Серийный номер не нужен.** У бесплатной лицензии Unity Personal
> серийного номера не существует в принципе — он бывает только у платных
> Pro/Enterprise. Не ищите его в настройках аккаунта, там его нет.

## Важно про безопасность

Раньше был способ без пароля: файл лицензии `.ulf` клался в секрет.
GameCI его удалил, поэтому пароль от аккаунта Unity придётся положить
в секреты GitHub.

**Настоятельно рекомендую завести отдельный аккаунт Unity только для
сборки** (любая почта, бесплатная Personal-лицензия). Причины:

- репозиторий публичный; секреты не видны в логах и недоступны из форков,
  но доступ к ним есть у любого, кто может писать в репозиторий;
- если что-то утечёт, пострадает пустой технический аккаунт, а не ваш
  основной с проектами и организацией.

Мне пароль сообщать не нужно — вы вводите его прямо в настройках GitHub.

## Шаг 1. Аккаунт Unity

1. Зайдите на https://id.unity.com — или зарегистрируйте отдельный аккаунт
   для сборки.
2. Убедитесь, что лицензия **Unity Personal** (бесплатная) активирована.
   Если нет: https://unity.com/products/unity-personal → *Get started*.
3. **Двухфакторное подтверждение (2FA) должно быть выключено** — иначе
   автоматический вход не пройдёт. Ещё один довод за отдельный аккаунт.

## Шаг 2. Добавить два секрета в GitHub

Репозиторий → **Settings** → **Secrets and variables** → **Actions** →
**New repository secret**. Добавьте по очереди:

| Имя секрета      | Значение                 |
|------------------|--------------------------|
| `UNITY_USERNAME` | почта аккаунта Unity     |
| `UNITY_PASSWORD` | пароль от этого аккаунта |

Имена должны совпадать точно, заглавными буквами.

## Шаг 3. Собрать APK

1. Вкладка **Actions** → workflow **Build Unity APK** → **Run workflow**.
2. Сборка идёт долго: 25–45 минут (Unity ставится на раннер, затем
   компилируется IL2CPP под ARM64). Повторные сборки быстрее за счёт кэша.
3. Готовый APK появится в **Releases** под тегом **apk-unity**, а также
   в артефактах запуска.

Дальше каждое изменение в папке `unity/` пересобирает APK автоматически.

## Если что-то пошло не так

- **Сборка сразу пропускается** — не найден один из секретов; в логе job
  «Проверка доступа к Unity» написано, какого именно.
- **Ошибка активации** — чаще всего включена 2FA либо неверный пароль.
- **Нет места на диске у раннера** — сообщите, уменьшу состав установки.
- **Не хотите класть пароль в секреты** — это разумно; тогда остаётся
  Godot-версия в папке `game/`: она собирается вообще без лицензии,
  и её APK уже лежит в релизе `apk-latest`.
