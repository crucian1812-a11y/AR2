# BJJ — игра про бразильское джиу-джитсу

Unity 6 (6000.0.80f1), URP, Android arm64. Сборка — только в GitHub Actions,
локально Unity нет.

## Устройство проекта

**В репозитории нет ни сцен, ни префабов, ни сериализованных ассетов Unity.**
Всё создаётся кодом — сцена собирается скриптом сборки, материалы и
URP-ассеты тоже. Подход перенесён из проекта «Медвежьи Приключения» в этом
же репозитории; зачем именно так — в [`../docs/bjj/FINDINGS.md`](../docs/bjj/FINDINGS.md) §2.

```
unity/
  Assets/
    Editor/
      BuildScript.cs           сборка APK, генерация сцены, URP, настройки плеера
      ModelImportSettings.cs   импорт FBX и текстур вместо .meta-файлов
    Scripts/
      Game/
        Positions.cs           позиции борьбы, очки, выгодность
        Transitions.cs         рёбра графа: приёмы, стоимость, шансы
        Match.cs               состояние схватки: позиция, силы, очки, часы
        Ai.cs                  соперник
        Arena.cs               зал: татами, трибуны, свет, туман
        Staging.cs             ракурс камеры для каждой позиции
        Res.cs                 загрузка модели и клипов
        FighterRig.cs          модель, анимация через Playables, материалы
        PostFx.cs              том пост-обработки, собранный кодом
        CameraDirector.cs      режиссура камеры, тряска, добивание
        GameRoot.cs            сборка схватки
        Bootstrap.cs           точка входа
      UI/
        Hud.cs                 часы, очки, силы, кнопки приёмов
        UiKit.cs, Gfx.cs       интерфейс кодом
    Shaders/
      BjjLit.shader            общий освещённый шейдер (Bjj/Lit)
      BjjSkin.shader           кожа: wrap-lighting и просвет (Bjj/Skin)
      BjjCloth.shader          ткань кимоно: sheen и намокание (Bjj/Cloth)
```

## Анимация без ассетов

Клипы проигрываются через **Playables**, а не через `AnimatorController`:
контроллер — это ассет, а их в проекте нет. Микшер на два входа даёт ровно
то, что нужно, — плавный переход между позициями.

Модель импортируется как **Generic**, а не Humanoid. Humanoid нормирует
позу через «мышцы» с пределами подвижности, а позиции борьбы как раз
предельные — он обрезал бы закрытую гвардию и крюки на спине. Клипы сняты
на том же скелете, что и модель, поэтому ретаргет не нужен вовсе.

## Ядро отделено от графики

`Match` не знает ни про модели, ни про анимации — он оперирует позициями и
силами. `FighterView` и `Staging` лишь показывают его состояние. Поэтому игра
уже играется на капсулах, а модели подключаются, не трогая правила.

## Проверка кода без Unity

```bash
sudo apt-get install -y mono-mcs      # один раз
bash tools/csharp-check/check.sh
```

Компилирует всё из `unity/Assets` против заглушек Unity API. Ловит опечатки
и ошибки типов за секунды — сборка Unity идёт 25–45 минут, узнавать из неё
про пропущенную точку с запятой незачем. Эта же проверка стоит отдельной
job в workflow и блокирует сборку.

## Сборка

Каждое изменение в `unity/` запускает `Build BJJ APK`. Готовый APK — в
разделе Releases под тегом **apk-bjj**. Про лицензию: [`../docs/bjj/LICENSE_SETUP.md`](../docs/bjj/LICENSE_SETUP.md).
