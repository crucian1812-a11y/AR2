# Медвежьи Приключения — версия на Unity 🐻

Порт игры на Unity 2022.3 (Built-in Render Pipeline). Godot-версия
осталась нетронутой в папке `game/`.

## Первый запуск

Unity требует активации лицензии — см. **[LICENSE_SETUP.md](LICENSE_SETUP.md)**.
Это делается один раз и занимает несколько минут. После этого сборка APK
идёт автоматически при любом изменении в `unity/`.

Готовый APK: раздел **Releases**, тег **apk-unity**.
Требуется 64-битный Android (arm64) 7.0+.

## Устройство проекта

Весь контент создаётся кодом — в репозитории нет бинарных ассетов Unity,
префабов и сцен. Сцена генерируется скриптом сборки.

```
unity/
  Assets/
    Editor/BuildScript.cs      сборка APK, создание сцены, настройки проекта
    Scripts/
      Audio/Snd.cs             синтез всех звуков и музыки
      Net/NetManager.cs        UDP-мультиплеер + поиск хостов в сети
      Game/                    игрок, монеты, враги, порталы, НПС, звезда
      Worlds/                  три мира и общие строительные помощники
      UI/                      меню, HUD, сенсорное управление
    Shaders/                   6 собственных шейдеров
  Packages/manifest.json
  ProjectSettings/ProjectVersion.txt
```

### Почему свои шейдеры

Материалы создаются в рантайме через `Shader.Find`, а Unity вырезает из
сборки шейдеры, на которые нет ссылок в сцене. Поэтому используются
собственные шейдеры (`Bear/Lit`, `Bear/Sky`, `Bear/Grass`, `Bear/Water`,
`Bear/Portal`, `Bear/Additive`), и `BuildScript` принудительно добавляет
их в **Always Included Shaders**.

## Проверка кода без Unity

Unity в этой среде нет, поэтому код проверяется компиляцией против
заглушек Unity API:

```bash
bash tools/csharp-check/check.sh
```

Скрипт компилирует всё из `unity/Assets` вместе с
`tools/csharp-check/UnityStubs.cs` через `mcs`. Ловит синтаксис, опечатки
и ошибки типов. Заглушки — только для проверки, в сборку не попадают.

## Мультиплеер

Собственный протокол поверх UDP, хост авторитетен:

- порт игры **8910/UDP**, обнаружение хостов **8911/UDP** (broadcast);
- клиенты шлют своё положение 20 раз в секунду, хост рассылает состояние
  всех игроков и врагов;
- каждые полсекунды хост шлёт полный снапшот (собранные монеты, побеждённые
  враги, мир, задание) — поэтому потерянные пакеты не ломают игру.

## Управление

- **Телефон:** джойстик слева, «Прыжок»/«Удар» справа, свайп справа — камера.
- **ПК:** WASD/стрелки, Space — прыжок, E или ЛКМ — удар, мышь с зажатой
  кнопкой — камера, Q/E — поворот камеры.
